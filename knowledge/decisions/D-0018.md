# D-0018 — Deliberate entry, connected surfaces and a fresh Jump to release

Rusty rejected bump-triggered gravity as unpredictable and approved holding Jump while
moving toward the wall the wearer is looking at, then following connected surfaces.
Releasing and pressing Jump again detaches, with a brief reattachment guard. Ordinary
walking and floor ledges retain world gravity. This supersedes D-0009's automatic
entry and packet-free input assumption, retaining its six-axis physics and synced frame.
D-0014 and D-0017's collision and movement authority remain requirements.

The baseline real-server experiment reproduced an ordinary ledge walk rotating to a
sideways frame with onGround true and no supporting face. The previous outer-corner
rule only checked whether a guessed box fit in air. The new adapter traces the actual
exposed block face; both entry and wrapping require support and a free box. Missing
support releases; a blocked upright release retains the valid old box until it fits.

Manual Jump is sampled before Minecraft auto-jump and sent before normal movement.
The input-only payload contains no position or requested frame. Four held input ticks,
forward intent and a view toward the contacted wall permit initial attachment. Holding
the entry key cannot detach; release plus a fresh press does. The release guard lasts
eight input ticks and also requires key release. Attached auto-jump is suppressed;
ordinary world-frame jumping is unchanged. Tooltips name the actual Jump binding.

The server applies pending release before replaying movement, reconstructing displacement
from the connection's saved movement origin. Inner and outer corner candidates must
reproduce all three reported coordinates through real collision and surface queries.
Vanilla speed, penetration and movement-error checks remain enabled. Client prediction
does not authorize a frame. Initial attachment cancels remaining outward jump momentum
so holding Jump does not bounce straight off the newly selected wall.

Vanilla's server movement handler inferred a jump from rising world Y and a false
on-ground bit. A real wearer climbing the wall triggered that inference, generating
outward momentum on the server alone. That inference now applies only in world gravity;
the explicit manual-input rule handles attached Jump. The entry threshold is 0.01
blocks/tick so the real client's 0.0196 airborne forward movement can attach during
the first held jump instead of waiting to land.
